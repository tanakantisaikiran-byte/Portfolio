### 2. Emotion Detection and Learning Support

**Internship Project — SmartBridge**

The system combines Machine Learning and Generative AI to provide study suggestions, motivational support, and learning guidance.

**Technologies:**
`Python` `TensorFlow` `BiLSTM` `BERT` `NLP` `Machine Learning` `Generative AI` `Google Gemini` `Streamlit` `SQLite`

**Key Features:**

* Text-based emotion detection
* BiLSTM and BERT models
* Keyword-based rule engine
* Hybrid late fusion
* Personalized learning guidance
* Google Gemini integration
* Offline fallback
* Student dashboard
* SQLite database
* Streamlit interface

**GitHub:**
https://github.com/tanakantisaikiran-byte/Emotion-Detection-Learning-Support
